Software 2: Panel Central de Control de Asistencia · Supabase Realtime & PostgreSQL

Conexión a Supabase Nube

Configura las credenciales compartidas con el Módulo Lector

Tabla requerida en PostgreSQL:

create table if not exists asistencias ( id uuid default gen_random_uuid() primary key, cedula text not null, nombre text not null, cargo text, tipo text not null, fecha_hora timestamptz default now() );

* Asegúrate de habilitar Realtime en la tabla asistencias desde la consola de Supabase (Database → Replication → Source → asistencias).
